## How to use it

1. Download the file from the project page and run it.
2. Start the game. It doesn't matter which one you launch first.
3. Press `Insert` in the game to open and close the menu. You can change this key in the menu settings.

Right-click any switch or button and press a key to give it its own hotkey. Your settings are saved in `%APPDATA%\STCheat`.
